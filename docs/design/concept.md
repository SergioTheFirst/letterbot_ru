# LetterBot — дизайн-концепция v2 (style-tile)

> Единый источник правды о внешности сайта. Направление: **«Тёплый операторский пульт»**.
> Светлая бумажная тема, инженерная честность, telegram-first. Никаких тёмных тем, градиентов и стекла.

---

## 1. Почему именно так

Продукт: локальный почтовый оператор для Windows — читает IMAP, ставит приоритеты, шлёт уведомления в Telegram.
Аудитория: фрилансеры, малый бизнес, инженеры, «технический заказчик» — люди, уставшие от шума в почте
и от маркетинга. Ключевые ценности бренда: **локальность, бесплатность, объяснимость, Telegram как интерфейс,
инженерная честность** («не притворяется умнее, чем есть»).

Отсюда визуальный язык: спокойная тёплая бумага вместо чёрного фона, «логирование» как сквозной мотив
(продукт буквально выводит лог-строки — это реальные строки с сайта, ничего выдуманного),
синий цвет Telegram как единственный акцент действия.

## 2. Палитра (токены по ролям)

| Токен | Значение | Роль |
|---|---|---|
| `--paper` | `#F6F3EC` | фон страницы — тёплая бумага, чистый белый запрещён |
| `--paper2` | `#EDE8DC` | чередующиеся полосы секций |
| `--card` | `#FCFAF4` | карточки и поверхности |
| `--ink` | `#1F2E36` | основной текст — глубокий сине-зелёный, не чёрный |
| `--muted` | `#5C6B74` | вторичный текст |
| `--muted2` | `#8A97A0` | третичный текст, пометки |
| `--line` | `rgba(31,46,54,.12)` | разделители, обводки |
| `--brand` | см. ниже | главное действие — синий Telegram |
| `--teal` | `#0E7C72` | ссылки, вторичные акценты, INFO |
| `--green` | `#2F7D4F` | успех, OK-статусы |
| `--amber` | `#A8620F` | «важно», WARN |
| `--red` | `#B23B3B` | «срочно», ERR |
| `--blue` | `#2C6FB0` | «низкий приоритет» |

Правила:
- Один цвет — одно значение. Синий `--brand` — только кликабельное/действие.
- Цвета статусов (красный/жёлтый/синий/зелёный) — только там, где это семантика продукта
  (приоритеты писем, статусы лога, кнопки снуза). В декоре их нет.
- Текст на `--paper` — только `--ink`/`--muted`/`--muted2`; все пары ≥ 4.5:1.

## 3. Типографика

| Роль | Семейство | Размер | Строка | Вес |
|---|---|---|---|---|
| Display (hero) | Golos Text | clamp(34px, 5vw, 58px) | 1.06 | 800–900, letter-spacing -0.02em |
| Title (h2 секций) | Golos Text | clamp(24px, 2.8vw, 36px) | 1.12 | 700 |
| Heading (h3/h4) | Golos Text | 18–20px | 1.3 | 600–700 |
| Body | Golos Text | 16–17px | 1.6 | 400 |
| Caption | Golos Text | 13px | 1.5 | 400 |
| Mono (код, лог, факты, бейджи) | JetBrains Mono | 12–14px | 1.6 | 400–500 |

Правила:
- Кириллица обязательна (Golos Text и JetBrains Mono — русские шрифты, проверено).
- Inter запрещён. Больше трёх семейств не используем.
- Дисплейные заголовки — `text-wrap: balance`; описания — `text-wrap: pretty`.
- Кавычки — только ёлочки, тире — только длинное, неразрывные пробелы после предлогов.
- Цифры в факт-барах и статусах — `tabular-nums`.
- Заголовки — про боль читателя, без канцелярита и стоп-слов (Unlock, Seamlessly, Empower, «в современном мире»).

## 4. Радиусы и отступы

Радиусы: `--r-sm: 6px; --r-md: 12px; --r-lg: 16px; --r-xl: 24px`.
- Кнопки: 10px (умеренные). Pill (999px) — только компактные бейджи-статусы.
- Концентричность: внешний радиус = внутренний + отступ.

Отступы (единственная шкала): `--s-4, --s-8, --s-12, --s-16, --s-24, --s-40, --s-56, --s-88, --s-128`.
- Плотность секций: 128 / 88 / 56 px (три уровня, чередование).
- Инлайн-значений в разметке нет. Оптические поправки (вынос кавычки) — помечены комментарием в CSS.

## 5. Кнопки

- `btn-primary` — фон `--brand`, белый текст, hover темнее, `:active { scale: 0.97 }`.
- `btn-secondary` — белая/карточная с обводкой `--line`, hover: тёмная обводка + фон.
- `btn-ghost` — текст-ссылка с подчёркиванием по hover.
- Названия — по действию и по-русски: «Скачать бесплатно», не «Начать».
- Состояния: покой / hover (только `@media (hover:hover) and (pointer:fine)`) / active / focus-visible (2px `--brand` outline, offset 3px; на тёмных полосах — светлая мятная рамка).
- Эмодзи в кнопках и заголовках — ноль. (Эмодзи допустимы только внутри мока Telegram-сообщения — это реальный интерфейс продукта.)

## 6. Карточки — три роли

1. **Плитка** — карточка возможностей на `--card` с тонкой обводкой-тенью (layered shadow, не generic-тень), скругление `--r-lg`.
2. **Лист наблюдения** — «панель» с mono-заголовком и полем для данных (mocks, лог-блоки), фон `--paper2`, `--r-md`.
3. **Тёмная акцент-полоса** — фон `--ink`, светлый текст, для финального призыва и ключевых метрик. Светлая рамка фокуса.

Наведение на некликабельные карточки — отсутствует (ложная афордансность).

## 7. Сквозной мотив: «линия обработки письма»

- В hero: горизонтальная линия конвейера `IMAP → Сегментация → Priority v2 → Telegram` с реальными
  данными из лога сайта (score=0.91, URGENT, reasons). Линия прочерчивается один раз при загрузке
  (единственная анимация страницы, `prefers-reduced-motion` отключает).
- Заголовки секций (eyebrow) — лог-строки: `[INFO] // против рынка` — mono, 12px, с цветной точкой статуса.
- Факты и метрики — mono-чипы с реальными числами (0₽, ∞, 10–15 мин, 3 ГБ, 0 серверов).
- Подвал — «системный статус»: версия, лицензия, контакты, моно-строка состояния.

Все числа на странице — только из контента сайта. Придумывать метрики запрещено.

## 8. Motion (по стандартам emilkowalski)

- Токены: `--ease-out: cubic-bezier(0.23,1,0.32,1)`, `--ease-in-out: cubic-bezier(0.77,0,0.175,1)`.
- Кнопки: press `scale(0.97)` 160ms ease-out; hover-переходы ≤150ms, только transform/opacity/цвет.
- UI-анимации < 300ms. `transition: all` запрещён. `scale(0)` запрещён.
- Единственная декоративная анимация — линия конвейера в hero (one-shot, 800ms, ease-in-out, потом покой).
- Аккордеон FAQ: height 200ms ease-out + opacity. Мобильное меню: drawer 300ms ease-out.
- `prefers-reduced-motion: reduce` — без движения, только cross-fade.
- Появление секций при скролле — удалено (шаблон нейрослопа).

## 9. Доступность

- Семантическая разметка: header/nav/main/footer, списки — `<ul>/<li>`.
- Skip-link первым в порядке табуляции.
- `:focus-visible` на всех интерактивных элементах (контраст рамки ≥ 3:1 на всех фонах).
- Тач-таргеты ≥ 44px (мобильное меню 47px, кнопки 44px).
- Контраст текста проверен скриптом по формуле WCAG: текст ≥ 4.5:1, крупный ≥ 3:1.
- `lang="ru"`, заголовки по уровням, `alt` у картинок, aria-expanded у аккордеона и меню.
