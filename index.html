LOCAL_FIRST

Ваш компьютер — не промежуточный сервер.

  • SQLITE Метаданные хранятся в data/mailbot.sqlite на вашем диске. Бэкап — копия файла.
  • IN-MEMORY Тела писем и содержимое вложений обрабатываются в памяти и не сохраняются.
  • IMAP READ-ONLY LetterBot не удаляет, не перемещает и не изменяет ни одного письма. Inbox остаётся как есть.
  • NO TELEMETRY Единственные внешние соединения — ваш IMAP-сервер и Telegram Bot API. Нулевая телеметрия.
  • NO CLOUD Серверов LetterBot не существует — некуда передавать данные.

По умолчанию ваша почта обрабатывается исключительно локально.

Внешние AI — только по вашему явному выбору в конфиге. Код открыт для аудита.

GRACEFUL_DEGRADATION

Если усилитель недоступен, система не исчезает.

Большинство AI-ботов при потере LLM либо молчат, либо продолжают притворяться.

LetterBot честно переходит в деградированный режим и остаётся полезным: базовые уведомления продолжают работать на детерминированном ядре. Вы получаете уведомление о деградации. При восстановлении LLM — нормальный режим возобновляется автоматически.

INSTALL

От ZIP до работающего оператора — 10–15 минут.

  1. 1
    Распаковать ZIP Например, в C:\LetterBot — путь без кириллицы и пробелов. Архив с GitHub Releases.
  2. 2
    Заполнить accounts.ini IMAP-хост, порт 993, логин, пароль приложения и токен Telegram-бота. Gmail — «пароль приложения», не основной.
  3. 3
    Запустить letterbot.bat Healthcheck всех ящиков, Telegram-polling. Первое уведомление — при следующем новом письме.

Python включён в дистрибутив.

FAQ

Частые вопросы

Нужна ли подписка?

Нет. LetterBot бесплатен навсегда. AGPL-3.0 open source. Без freemium, без скрытых платежей. Поддержка — добровольная.

Нужен ли OpenAI?

Нет. OpenAI не требуется. По умолчанию LetterBot работает в детерминированном режиме без внешних AI. GigaChat и Cloudflare Workers AI — опциональные усилители.

Письма уходят куда-то?

Нет. Обработка локальная. SQLite на вашем компьютере. Никаких серверов LetterBot не существует. Единственные внешние соединения — ваш IMAP-сервер и Telegram Bot API.

Сколько ящиков можно подключить?

Неограниченное количество IMAP-аккаунтов. Каждый маршрутизируется в отдельный Telegram-чат. Дайджесты не дублируются.

Как выставляется приоритет?

Детерминированный движок Priority v2: анализирует тип письма, сумму, срок, вложения, историю отправителя. Каждое решение содержит список причин.

Работает на старом ПК?

Да. Протестировано на Intel Celeron N4020, 3 ГБ RAM. One-folder release: распаковать, заполнить .ini, запустить .bat.
