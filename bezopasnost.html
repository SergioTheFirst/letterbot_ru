Безопасность и приватность

LetterBot спроектирован так, чтобы ваша почта не покидала ваш компьютер без явного выбора с вашей стороны.

НУЛЕВЫЕ СЕРВЕРЫ LETTERBOT

Никаких серверов LetterBot не существует. Некуда передавать данные по умолчанию. Единственные исходящие соединения: ваш IMAP-сервер и Telegram Bot API.

ЛОКАЛЬНАЯ SQLITE

Все метаданные хранятся в data/mailbot.sqlite на вашем диске. Резервная копия — просто скопировать файл. Удаление всех данных — удалить файл.

IMAP READ-ONLY

LetterBot подключается к почте только на чтение. Он никогда не удаляет, не перемещает, не помечает и не изменяет ни одного письма.

БЕЗ OPENAI

OpenAI не поддерживается и не используется. Опциональные LLM-провайдеры: GigaChat (Сбер) и Cloudflare Workers AI. По умолчанию — полностью детерминированный режим без внешних AI.

НУЛЕВАЯ ТЕЛЕМЕТРИЯ

LetterBot не собирает и не отправляет никакой телеметрии. Проверяемо в открытом исходном коде на GitHub.

ЧТО ОТПРАВЛЯЕТСЯ ПРИ LLM

Если вы включаете опциональный LLM — только текст тела письма. Вложения, сырой email, адресная книга, история не передаются.

Итог: По умолчанию ваша почта обрабатывается исключительно локально. Внешние AI — только по вашему явному выбору в конфиге. Код открыт для аудита.
